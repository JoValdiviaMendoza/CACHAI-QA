
#capstone_2026_duoc_alameda

Nombre del proyecto: CACHAI-QA DUOC Alameda

Descripción: Proyecto denominado CACHAI-QA, consiste en desarrollar un framework de automatización de pruebas innovador con un enfoque "plug & play" "Listo para usar".
Su objetivo es que el usuario solo tenga que ingresar la URL de una página web en un archivo de configuración; a partir de ahi, el sistema escanea automáticamente el sitio y genera pruebas genéricas para el Front-End.
Estas pruebas verifican relas universales de calidad, como la ausencia de enlaces rotos, la correcta carga de imágenes y el funcionamiento de los botones principales.
